# Visual Forge

**Visual Forge** is a pocket-first field system for creating, transforming, explaining, sequencing, diagnosing, and repairing visual-generation prompts.

It is deliberately simple at the repository level: the entire application is `index.html`. No framework, package manager, CDN, font service, API, build step, or runtime dependency is required.

## Open it

GitHub Pages target:

`https://westkitty.github.io/visual_forge/`

The same `index.html` can also be downloaded and opened as a standalone local HTML artifact.

## What is inside

- 25 routed learning and tool modes
- Prompt Lab with local presets and constraint switches
- Prompt Doctor for failure-specific repair blocks
- Shot Builder and Lighting Recipe tools
- Reference Authority Map builder
- Wonder Lab technique deck
- Recipe Reactor that forges coherent visual-direction recipes and sends them into Prompt Lab
- Pocket Forge, an iPhone-specific one-thumb workflow and Home Screen guide
- separate-image anti-collage workflow
- character turnaround and dossier methodology
- style-transfer and minimal-delta editing rules
- infographic hierarchy and grounding workflow
- canon / closed-world controls
- world reconstruction
- comics, storyboards, game assets, posters, icons, product imagery, continuity QA, and repair
- local progress, display preferences, search, and copy controls

## iPhone

The interface is designed mobile-first with safe-area handling and 44pt-or-larger primary controls.

When using the Pages version in Safari, choose **Share → Add to Home Screen → Open as Web App → Add** for an app-shaped launch experience.

## Release invariant

`index.html` must remain useful by itself. Repository automation may validate or publish it, but the visual field system does not depend on repository tooling to function.
